# HR 통계 분석 노트

HR 데이터애널리틱스 강의의 11가지 분석 기법과 설문 논문에서 자주 쓰는 6가지 통계 기법을 학습하는 웹사이트입니다.

- 사이트: https://dreamdaddy80.github.io/hr-analytics-study/
- 구성: 통계 기초 → Part 1~4 (평균 비교, 범주 예측, 회귀, 이직·유형·관계) → Part 5 (논문 통계) → Part 6 캡스톤(이직 데이터 통합 실습) → 정리(종합 시나리오 퀴즈 · 오답노트 · 해석 기준표 · 용어집 · 추가 학습 로드맵)
- 각 모듈: 비유 · 원리 · 인터랙티브 시뮬레이터 · 결과표 해석 · R 코드(SPSS·jamovi 메뉴 경로 탭) · 실습 데이터 CSV와 기대 출력 · 생성형 AI 프롬프트와 검증 체크리스트 · 해석 문장 쓰기 연습 · 확인 퀴즈
- 실습 데이터는 강의 원자료가 아니라, 원자료·논문의 평균·표준편차·상관을 재현하도록 브라우저에서 seed 고정으로 생성하는 가상 데이터입니다.
- 학습 기록(완료 표시, 오답노트, 쓰기 초안)은 각 브라우저의 localStorage에만 저장됩니다.
- 단일 파일(index.html)로 동작하며 별도 빌드가 필요 없습니다.
